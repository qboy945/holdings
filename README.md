# 緣來喝茶持股人生

台股持股健檢工具。純前端、純本機計算，不上傳任何資料。

## 功能

- 每檔持股：股數、成本均價、現價、市值、未實現損益、報酬率
- 集中度：單一持股占比、前三大占比、HHI 集中度指數
- 產業曝險：依證交所 33 類產業分類（ETF 不計入單一產業）
- 資產結構：個股 vs ETF 比重、股票 vs 現金比重
- 壓力測試：最大持股跌 30% 對總資產的影響

## 資料來源

- 股票名稱與產業別：證交所開放資料 `t187ap03_L`
- ETF 清單：證交所開放資料 `t187ap47_L`

價格由使用者手動輸入，非即時行情。

## 界線

本工具僅整理使用者自行輸入的持股資料，不提供買賣建議、不預測報酬、不構成投資推薦。
